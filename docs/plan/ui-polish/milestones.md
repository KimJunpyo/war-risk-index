## M1. 반응형·스크롤바 기반

홈 전체가 쓰는 브레이크포인트 4개와 페이지 컨테이너, 스크롤바 스타일을 정한다. 스크롤바는 새 라이브러리 없이 직접 구현한다(plan.md Q3 확정). 이 마일스톤만 끝나도 기존 화면이 새 브레이크포인트에서 깨지지 않고, 모든 OS에서 네이티브 스크롤바 대신 thumb만 보이는 것을 확인할 수 있다.

**완료 조건**
- `frontend/src`·`frontend/app` 전체에서 `sm:`·`2xl:` 접두사 grep 결과 0건이고, `globals.css`에 `md` 48rem, `lg` 67.5rem, `xl` 90rem 세 브레이크포인트만 정의돼 있다.
- 폭 1440px에서 홈 콘텐츠 폭이 1280px(좌우 여백 제외)이고 가운데 정렬된다. 폭 360px에서 좌우 여백이 16px이다.
- 네 폭 모두 가로 스크롤 0.
- 페이지·주목 국가 목록·뉴스 목록·가이드 모달에서 네이티브 스크롤바(트랙·화살표)가 보이지 않고 겹쳐 그린 thumb만 보인다(Windows Chrome·Edge·Firefox에서 확인).
- 같은 네 곳에서 스크롤바 공간이 0이다(`offsetWidth - clientWidth == 0`, 페이지는 `innerWidth - clientWidth == 0`). 뉴스 목록에 스크롤이 생기거나 없어져도 첫 항목 x좌표·폭 변화가 0px이다.
- thumb가 스크롤 위치를 따라가고 드래그로 스크롤되며, 휠·키보드·터치 스크롤은 네이티브 그대로 동작한다.
- thumb 계산 순수 함수의 `node --test` 테스트가 통과하고, `frontend/package.json` 의존성이 바뀌지 않았다.

**이슈**
- 1-1 커스텀 브레이크포인트와 페이지 컨테이너 정의 (`issues/1-1-breakpoints-container.md`)
- 1-2 오버레이 스크롤바 직접 구현: thumb만 표시, 레이아웃 공간 0 (`issues/1-2-overlay-scrollbar.md`) — 이전 초안의 1-2(표준 CSS)와 1-3(오버레이)을 합침

## M2. 화면별 반응형과 가이드 모달

`plan.md` 5-2 배치표를 홈의 각 영역에 적용하고, 가이드 모달 여행경보 표 줄바꿈을 고친다. 대피소 내부(검색·페이지)와 푸터 내부는 M3에서 다룬다.

**완료 조건**
- 네 폭 각각에서 `plan.md` 5-2 표의 헤더~FAQ·가이드 모달 행과 열 수·순서·고정 폭이 일치한다(개발자 도구 요소 검사로 폭 확인, 허용 오차 ±1px).
- 가이드 모달 여행경보에서 단계(`1단계`~`4단계`)와 각 기관 단계 이름의 주 문구(괄호 앞 부분)가 네 폭 모두 한 줄이다.
- 1080·1440px에서 패널 그리드에 빈 칸이 없다(추이·위협 사건이 왼쪽 열에 붙어 쌓이고, 뉴스가 오른쪽 두 행을 차지).
- 네 폭 모두 가로 스크롤 0, 기존 기능(대상 선택, 지도 확대, 체크리스트 저장, 대피소 찾기, 연락처) 동작이 그대로다.

**이슈**
- 2-1 상단 영역 반응형: 헤더, 지도+주목 국가, 이번 주 변화, 국가 쌍 탭 (`issues/2-1-top-sections-responsive.md`)
- 2-2 본문 영역 반응형: 요약, 체크리스트·대피소·재외공관 배치, 패널 그리드, 과거 사례, FAQ (`issues/2-2-body-sections-responsive.md`)
- 2-3 가이드 모달 반응형과 여행경보 4단계 표 줄바꿈 수정 (`issues/2-3-guide-modal-advisory-table.md`)

## M3. 대피소 찾기·푸터 개선

대피소 결과를 지역·주변 전체에서 검색·페이지로 볼 수 있게 하고, 푸터를 개편한다.

**완료 조건**
- "경상남도 창원시" 지역 조회 시 결과 총 개수 527곳(로컬 `data/shelters.csv` 기준)이 표시되고, 10곳씩 마지막 페이지(53쪽)까지 이동할 수 있다.
- 결과 검색창에 단어를 입력하면 200ms 안에 이름 또는 주소에 그 단어가 들어 있는 대피소만 남고 1쪽으로 돌아간다.
- 서울시청 좌표(37.57, 126.98)로 위치 조회 시 5km 안 대피소 전부(로컬 데이터 기준 476곳)를 거리순 페이지로 볼 수 있다.
- 푸터에 개인 작업물 고지, 실제 사용하는 데이터 출처 12개(링크 포함, 목록은 3-3), GitHub·LinkedIn 링크(표시 이름 KimJunpyo)가 있고, `frontend/src`·`frontend/app`·`frontend/public` grep 결과 "FORMULA" 0건.
- 위치 개인정보 기존 인수 조건(로드 시 위치 팝업 없음, 좌표 소수 2자리, 브라우저 저장소 미사용)이 그대로 통과한다.

**이슈**
- 3-1 대피소 조회 상한 조정과 전체 건수 응답 (`issues/3-1-shelter-api-limits.md`)
- 3-2 대피소 결과 키워드 검색·페이지네이션·카드 배치 (`issues/3-2-shelter-search-pagination.md`)
