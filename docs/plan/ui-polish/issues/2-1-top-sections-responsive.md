# 상단 영역 반응형: 헤더, 지도+주목 국가, 이번 주 변화, 국가 쌍 탭

## 배경

`plan.md` 5-2 배치표의 위쪽 네 영역을 네 폭(360/768/1080/1440)에 맞춘다. 지금은 360px에서 헤더 버튼이 줄바꿈되고, 지도 패널 제목 줄에 토글이 같이 있어 좁으며, 국가 쌍 카드가 1열로 7개 쌓여 길다.

## 범위

- 포함: 헤더(`HomePage.tsx` `<header>`), `WorldMap`(패널 제목 줄, 지도+주목 국가 그리드, 주목 국가 목록 높이), `WeeklyMovers`, `PairTabs`
- 제외: 지도 툴팁의 터치 대응, 지도 확대 동작 변경, 요약 이하 영역(2-2)

## 목표 배치 (plan.md 5-2 발췌)

| 영역 | 360 | 768 | 1080 | 1440 |
|---|---|---|---|---|
| 헤더 | 제목 20px + LiveBadge + 오른쪽 끝 "가이드" 버튼이 한 줄 | 제목 24px, 버튼 "가이드 · 여행경보 단계" | 같음 | 같음 |
| 지도 + 주목 국가 | 토글은 제목 아래 줄. 지도 전체 폭, 아래 주목 국가 1열(최대 높이 320px) | 제목·토글 한 줄. 아래 주목 국가 2열(최대 높이 320px) | 지도 + 오른쪽 목록 260px, 목록 높이 = 지도 높이 | 오른쪽 목록 300px |
| 이번 주 변화 | 세로 2블록 | 2열 | 2열 | 2열 |
| 국가 쌍 탭 | 2열, 보조 문구는 점수 아래 줄 | 3열 | 4열 | 4열 |

## 할 일

1. 헤더: 360에서 버튼 문구를 "가이드"로 줄이고(`md` 이상에서 전체 문구), 제목·배지·버튼이 한 줄에 들어가게 한다. 버튼의 접근 가능한 이름은 모든 폭에서 "가이드 · 여행경보 단계"로 같게 둔다(`aria-label` 또는 시각적으로 숨긴 텍스트).
2. `Panel`의 `action`이 360에서 제목 아래 줄로 내려가도록 한다. `Panel`은 공용 컴포넌트이므로 다른 패널(뉴스 기간 토글 등)도 같은 규칙을 따르게 되는지 확인해 PR에 적는다.
3. `WorldMap` 그리드: 기본 1열, `lg`에서 `[minmax(0,1fr)_260px]`, `xl`에서 `[minmax(0,1fr)_300px]`. 주목 국가 목록 최대 높이는 `lg` 미만 320px, `lg` 이상은 지도 높이에 맞춘다(CSS로 가능하면 CSS, 아니면 기존 `boxRef` 크기 활용). 숫자는 상수로 둔다.
4. 주목 국가 목록 `md`~`lg` 미만 2열.
5. `WeeklyMovers`: 기본 1열, `md` 2열(1-1에서 `sm`→`md` 이전된 상태 확인).
6. `PairTabs`: 기본 2열, `md` 3열, `lg` 4열. 360에서 카드 안 보조 문구(실시간 24시간 점수)를 큰 점수 아래 줄로 내린다.

## 인수 조건

- [ ] 폭 360px에서 헤더의 제목·LiveBadge·가이드 버튼 세 요소의 `getBoundingClientRect().top` 차이가 8px 이하다(한 줄).
- [ ] 폭 360px에서 가이드 버튼 문구가 "가이드"이고, 768px 이상에서 "가이드 · 여행경보 단계"다. 모든 폭에서 버튼의 접근 가능한 이름(개발자 도구 Accessibility 탭)이 "가이드 · 여행경보 단계"다.
- [ ] 폭 360px에서 지도 색 기준 토글이 "세계 지도" 제목보다 아래에 있고, 768px 이상에서 같은 줄에 있다.
- [ ] 폭 360px·768px에서 주목 국가 목록이 지도 아래에 있고 목록 높이가 320px 이하이며 넘치면 내부 스크롤된다. 768px에서 목록이 2열이다.
- [ ] 폭 1080px에서 주목 국가 영역 폭이 260px, 1440px에서 300px이다(±1px). 두 폭에서 목록 영역 아래 끝과 지도 아래 끝의 차이가 1px 이하다.
- [ ] 이번 주 변화가 360px에서 1열, 768·1080·1440px에서 2열이다.
- [ ] 국가 쌍 카드가 360px에서 2열, 768px에서 3열, 1080·1440px에서 4열이다. 360px에서 카드 안 이름·배지·점수·보조 문구가 카드 밖으로 넘치지 않는다(각 카드 `scrollWidth <= clientWidth`).
- [ ] 지도 클릭·확대 버튼·주목 국가 선택·국가 쌍 선택이 네 폭에서 모두 동작한다.
- [ ] `frontend`에서 `npx tsc --noEmit`, `npm run lint` 오류 0건이다.
- [ ] `.venv\Scripts\python.exe -m pytest tests` 전부 통과한다.
- [ ] `node --test frontend/src/**/*.test.ts` 전부 통과한다.
- [ ] 브라우저 폭 360 / 768 / 1080 / 1440px에서 네 영역을 확인했고, 각 폭에서 `document.documentElement.scrollWidth <= window.innerWidth`가 `true`, 콘솔 오류 0건이다.
