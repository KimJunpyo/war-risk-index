# 본문 영역 반응형: 요약, 체크리스트·대피소·재외공관 배치, 패널 그리드, 과거 사례, FAQ

## 배경

`plan.md` 5-2 배치표의 요약 이하 영역을 네 폭에 맞춘다. 지금은 요약 영역이 하나의 `flex-wrap` 안에 점수·여행경보·체크리스트·대피소·연락처를 모두 넣어 폭에 따라 배치가 우연히 정해지고, 1024px 이상 패널 그리드에서 위협 사건 패널이 `lg:col-span-2`라 뉴스 패널(`lg:row-span-2`) 옆 두 번째 행 왼쪽 칸이 빌 수 있다(정적 분석, 브라우저 확인 필요).

## 범위

- 포함: `HomePage.tsx` 요약 `section` 구조, 여행경보 줄, 체크리스트와 대피소·재외공관의 바깥 배치, 패널 그리드(`RiskHistory`·`NewsFeed`·`CatalystPanel`·`PastCases`), FAQ, `ActionGuide` 항목 열 수, `EmbassyContacts` 공관 목록 열 수
- 제외: 대피소 위젯 안쪽(검색·페이지·결과 카드, 3-2), 푸터(3-3), 가이드 모달(2-3)

## 할 일

1. 요약 `section`을 "제목·점수 블록 / 점수 구성 문장 / 여행경보 / 행동 영역(체크리스트 + 대피소 또는 재외공관)"으로 나누고 각 블록을 위 표대로 배치한다. 대피소·재외공관 표시 조건(한국 또는 한국이 낀 쌍 → 대피소, 해외 나라 → 재외공관)은 바꾸지 않는다.
2. 여행경보 줄: 360에서 기관별 목록(`ul`), `md` 이상에서 기존 한 문단. 외교부 맨 앞 순서·"단계 설명" 버튼·링크 새 탭 동작은 유지한다.
3. `ActionGuide` 항목 열 수를 부모 배치에 따라 1열/2열로 바꿀 수 있게 한다(예: `columns` prop 또는 컨테이너 쿼리). 방법은 PR에 적는다.
4. 패널 그리드: `CatalystPanel`의 `lg:col-span-2`를 빼고 왼쪽 열 두 번째 행에 두며, `NewsFeed`는 `lg:row-span-2` 유지, `PastCases`는 `lg:col-span-2` 유지. 오른쪽 열 폭 `lg` 360px, `xl` 400px. 뉴스 목록 최대 높이 360·768·1080 이상 각각 480/560/720px(상수).
5. `EmbassyContacts` 공관 목록 `md`~`lg` 미만 2열.
6. FAQ는 클래스 변경이 필요 없으면 확인만 하고 PR에 "변경 없음"으로 적는다.
