# 전쟁 가능성 지수 서비스 개편 기획안

작성일: 2026-11-09 · 상태: 초안(사용자 컨펌 전)

## 1. 목표

일반인이 "지금 이 나라가 평소보다 얼마나 시끄러운가, 나는 무엇을 하면 되는가"를 한 화면에서 알 수 있게 한다.

1. 예측력이 확인되지 않은 실험 기능을 화면과 코드에서 없앤다.
2. 화면에 남은 정보 중 불완전한 것(무관 기사, 빈 칸, 전문 용어)을 정리한다.
3. 이미 가진 데이터(GDELT 점수 이력, 사례 검증 결과, 행동 권고)로 새 정보를 만든다.
4. 무료 공공데이터(외교부·행정안전부)로 실제 행동에 쓰는 정보(여행경보, 대피소, 영사 연락처)를 붙인다.

## 2. 대상 사용자

- 일반인. 통계 용어(σ, 기준선, 촉매)를 모른다고 가정한다.
- 주 사용 장면
  - 한반도 긴장 뉴스를 보고 "지금 위험한가"를 확인하려는 국내 거주자
  - 해외 여행·출장·체류 예정이거나 체류 중인 사람
  - 가족의 해외 체류지를 확인하려는 사람

## 3. 원칙

1. **불완전한 것은 보여주지 않는다.** 값이 없거나 신뢰할 수 없는 칸은 "준비 중"·"없음" 문구 대신 칸 자체를 렌더링하지 않는다. 판정 기준은 이슈마다 인수 조건에 적는다.
2. **예측처럼 보이게 하지 않는다.** 사례 비교 등에서는 개전 사례와 대조군(위기였지만 전쟁 없음)을 함께 보여 준다. 근거: `FORMULA_v1.md` 검증 결과 "개전 여부는 구분하지 못한다".
3. **공식 경보가 우선이다.** 정부 경보·안내는 출처와 발표일을 함께 표시하고, 점수에는 섞지 않는다.
4. **무료 데이터만 쓴다.** 유료 API 금지. 키가 필요한 API는 `.env`로 받고, 키가 없으면 해당 기능만 꺼진다(다른 화면은 정상).
5. **개인정보를 최소로 다룬다.** 위치는 사용자가 버튼을 눌렀을 때만 요청하고, 서버에 원 좌표를 저장·기록하지 않는다.
6. 데이터 파일은 기존처럼 E 드라이브의 프로젝트 `data/`·`out/`(git 제외)에 둔다.

### 새로 만들 것

- 이번 주 변화 Top 5, 과거 위기 사례 비교, 비상 대비 체크리스트(기존 권고 카드 확장)
- 외교부 여행경보, 내 주변 민방위 대피소, 재외공관·영사콜센터 연락처
- `.env` 로딩 기반(현재 `.env` 파일·로딩 코드 없음)

### 없앨 것

- 뉴스룸 위협 신호(ThreatPanel, `/api/threat`, `ai_threat.py`, `newsroom.py`, `threat_lexicon.py`, `newsroom.json`, 1시간 주기 수집). 근거: AUC 0.23(무작위 0.5보다 낮음, 사용자 측정값), 타국 기사 혼입.

### 확인한 사실 중 기획에 영향 주는 것

- `docs/design/` 시안이 없다. 모든 이슈의 "관련 시안"은 "없음"이며, 레이아웃은 기존 `Panel` 컴포넌트와 홈 그리드를 따른다.
- FAQ(`faq.ts`), `llms.txt`, footer, `FORMULA_v1.md`에는 뉴스룸·위협 신호 언급이 없다(grep 0건). 1번 마일스톤에서는 "0건 유지"만 확인한다.
- 2022년에는 GDELT 2.0 점수가 없어 종합 점수 = 일별 뉴스 집계 점수다. 과거와 현재를 비교할 때는 양쪽 모두 일별 집계 7일 점수(`weekly`)를 쓴다.
- 뉴스는 Google News RSS 한국어(`hl=ko`) 검색이라 제목 대부분이 한국어다.
- 저장소에 테스트 프레임워크가 없다. 백엔드는 모듈별 `self_check()` + 수동 실행, 프론트는 `tsc`·`eslint`가 검증 수단이다.
- 현재 브랜치 `chore/initial-upload`에 커밋되지 않은 변경 18건(`newsroom.py`·`newsroom.json` 수정 포함)이 있다. 1번 마일스톤 시작 전에 정리가 필요하다.

## 5. 사용자 흐름 (개편 후)

1. 홈 접속 → 세계지도와 "이번 주 변화"(많이 오른/내린 나라 각 5개)를 본다.
2. 지도나 Top 5 항목, 국가 쌍 탭을 눌러 대상을 고른다.
3. 요약 영역에서 종합 점수, (값이 있을 때만) 실시간 점수, 상태 배지, 정부 여행경보(외교부·미·영)를 본다.
4. 점수 구간에 맞는 비상 대비 체크리스트를 확인하고 항목을 체크한다(브라우저에만 저장).
5. 국가 쌍이면 "과거 위기 때 점수"에서 현재 점수와 과거 개전·대조군 사례를 나란히 본다.
6. 해외 나라를 골랐으면 그 나라의 재외공관 연락처와 영사콜센터 번호를 본다.
7. "내 주변 대피소" 버튼 → 위치 허용 시 가까운 민방위 대피소 목록, 거부 시 지역 선택으로 찾는다.
