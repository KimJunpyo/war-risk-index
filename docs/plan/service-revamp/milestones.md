## M1. 실험 기능 제거: 뉴스룸 위협 신호

예측력이 확인되지 않은(AUC 0.23, 타국 기사 혼입) 뉴스룸 위협 신호를 화면·API·수집·스크립트에서 모두 없앤다.

**완료 조건**
- 홈 화면에 "뉴스룸 위협 신호" 패널이 없다.
- `GET /api/threat`가 404를 반환한다.
- 백엔드 기동 후 `data/newsroom/`, `data/ai_threat/`에 새 파일이 생기지 않는다(1시간 이상 관찰).
- 저장소 전체(`node_modules`·`.venv`·`.git`·`data`·`out` 제외)에서 `newsroom|ai_threat|threat_lexicon|ThreatPanel|useThreat|/api/threat` grep 결과 0건.
- 나머지 홈 화면(지도, 쌍 탭, 요약, 추이, 뉴스, 촉매, FAQ)이 제거 전과 같게 동작한다.

**이슈**
- 1-1 뉴스룸 위협 신호 프론트엔드 제거 (`issues/1-1-remove-threat-frontend.md`)
- 1-2 뉴스룸 위협 신호 백엔드·수집 스크립트 제거 (`issues/1-2-remove-threat-backend.md`)

## M2. 불완전 표시 정리

화면에 남는 정보 중 무관하거나 비어 있거나 전문 용어인 것을 정리한다. 원칙: "불완전한 것은 보여주지 않는다".

**완료 조건**
- 국방 뉴스 패널의 모든 기사 제목에 대상 나라 이름(한국어 또는 영어, 별칭 포함)이 들어 있다. 남는 기사가 0건이면 패널이 렌더링되지 않는다.
- 실시간 점수가 없는 대상에서 "실시간 24시간" 라벨·값·"기준선 준비 중" 문구가 모두 보이지 않는다.
- 홈 화면에 "촉매" 단어가 보이지 않는다.

**이슈**
- 2-1 국방 뉴스 제목 필터와 0건 시 패널 숨김 (`issues/2-1-news-title-filter.md`)
- 2-2 실시간 점수 없는 대상의 실시간 칸 숨김 (`issues/2-2-hide-empty-live-score.md`)
- 2-3 위협·경고 사건 패널 문구를 일반인 언어로 (`issues/2-3-catalyst-plain-language.md`)

## M3. 자체 데이터 기반 신규 기능

외부 의존 없이 이미 있는 점수 이력·사례 검증·행동 권고로 새 정보를 만든다.

**완료 조건**
- 홈 화면에 이번 주 많이 오른/내린 나라가 각각 최대 5개 표시되고, 값이 `out/country_index.csv`로 손계산한 결과와 일치한다.
- 국가 쌍을 선택하면 과거 위기 사례(개전·대조군 모두)의 직전일 점수와 현재 점수가 함께 표시되고, 러시아–우크라이나 2022 값이 `FORMULA_v1.md` 검증 표(142)와 반올림 기준으로 일치한다.
- 선택 대상의 점수 구간에 맞는 비상 대비 체크리스트가 출처 표기와 함께 표시되고, 체크 상태가 새로고침 후에도 유지된다.
- 세 기능 모두 외부 네트워크 요청을 새로 만들지 않는다(개발자 도구 Network에서 `localhost:8000` 외 신규 요청 0건).

**이슈**
- 3-1 이번 주 변화 Top 5 (`issues/3-1-weekly-movers.md`)
- 3-2 과거 위기 사례와 현재 점수 비교 (`issues/3-2-past-case-comparison.md`)
- 3-3 점수 구간별 비상 대비 체크리스트 (`issues/3-3-emergency-checklist.md`)

## M4. 공공데이터 연동

무료 공공데이터포털 API(키는 `.env`)로 여행경보·대피소·영사 연락처를 붙인다. 각 이슈의 첫 할 일은 API 실체 확인이다.

**완료 조건**
- `.env`에 키가 없을 때 백엔드가 정상 기동하고 M4 기능만 화면에서 숨겨진다(다른 영역 정상).
- 키가 있을 때 선택한 나라의 외교부 여행경보 단계·발표일이 미 국무부·영국 FCDO와 함께 표시된다(외교부 데이터가 있는 나라 한정).
- "내 주변 대피소" 버튼을 눌러 위치를 허용하면 가까운 대피소가 거리순으로 표시되고, 거부해도 지역 선택으로 대피소를 찾을 수 있다.
- 해외 나라를 선택하면 해당 나라 재외공관 연락처와 영사콜센터 번호가 출처와 함께 표시된다.
- 서버 접근 로그·파일 어디에도 사용자의 원 좌표(소수점 3자리 이상)가 남지 않는다.

**이슈**
- 4-1 공공데이터 API 키 `.env` 설정 기반 (`issues/4-1-env-api-key-setup.md`)
- 4-2 외교부 국가·지역별 여행경보 연동 (`issues/4-2-mofa-travel-advisory.md`)
- 4-3 민방위 대피시설 데이터 수집과 조회 API (`issues/4-3-shelter-data-api.md`)
- 4-4 내 주변 대피소 화면 (`issues/4-4-nearby-shelter-ui.md`)
- 4-5 재외공관·영사콜센터 연락처 (`issues/4-5-embassy-contacts.md`)
