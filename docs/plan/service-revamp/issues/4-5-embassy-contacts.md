# 재외공관·영사콜센터 연락처

## 배경

권고 문장에 "해외 체류 중이면 영사 연락처·재외국민 등록 확인", "대사관의 철수·대피 안내 따르기"가 있지만 연락처는 화면에 없다. 해외 나라를 선택했을 때 그 나라의 대한민국 재외공관 연락처와 영사콜센터 번호를 보여준다.

## 범위

- 포함: 재외공관 데이터 수집(주기 갱신), 국가별 조회 API, 요약 영역 아래 연락처 표시
- 제외: 공관 위치 지도, 영사 서비스 예약·신고 연동, 대한민국(KOR) 선택 시 표시

## 할 일

1. **API 확인(첫 할 일)**: 공공데이터포털에서 외교부 재외공관 정보 API의 정확한 이름, 응답 필드(공관명, 국가 코드 형식, 주소, 대표 전화, 긴급(근무시간 외) 전화, 누리집), 갱신 주기, 호출 한도, 라이선스를 확인해 PR 설명에 적는다. 확인하지 못한 사실은 단정하지 않는다(plan.md Q13).
2. 영사콜센터 번호를 외교부 공식 누리집 등 1차 출처에서 확인하고 출처 URL·확인일과 함께 상수로 둔다(Q16). 데이터 API에 포함돼 있으면 그 값을 쓴다.
3. 수집 결과를 `data/embassies.csv`(git 제외)에 저장하고 하루 1회 갱신한다. 실패해도 다른 갱신을 막지 않는다.
4. `/api/countries`의 각 나라에 공관 목록을 넣거나 `GET /api/countries/{code}/embassies`를 추가한다(응답 크기를 보고 PR에서 택일). 키·데이터가 없으면 빈 목록.
5. 92개국 중 공관 데이터와 연결되지 않는 나라 목록을 PR에 적는다(겸임 공관이 있는 경우 처리 방식 포함).
6. 프론트에 연락처 영역을 만든다. 전화번호는 `tel:` 링크, 누리집은 새 탭 링크, 하단에 출처·기준일. footer 데이터 출처에 추가한다.
