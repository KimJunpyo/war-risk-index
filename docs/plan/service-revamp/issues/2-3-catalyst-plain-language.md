# 위협·경고 사건 패널 문구를 일반인 언어로

## 배경

CatalystPanel은 GDELT에서 "군사력 위협·최후통첩·무력 시위"로 분류된 사건을 보여준다. 제목 "⚡ 촉매 신호", "일별 언급량", "언급 N" 같은 표현은 일반인이 뜻을 알기 어렵다. 또 `FORMULA_v1.md` 검증 결과 이 신호는 개전과 대조군을 가르지 못하므로, 많다고 전쟁이 난다는 뜻이 아님을 화면에 밝힌다.

## 범위

- 포함: 화면 문구(제목, 부제, 소제목, 단위, 설명, aria-label)
- 제외: 백엔드 사건 분류 이름(`군사력 위협`·`최후통첩`·`무력 시위`), 집계 방식, 코드 주석

## 제안 문구 (plan.md Q7, PR 전 사용자 확정)

| 위치 | 현재 | 제안 |
|---|---|---|
| 패널 제목 | ⚡ 촉매 신호 | ⚡ 위협·경고 사건 |
| 제목 옆 | 위협 · 최후통첩 · 무력 시위 | 군사 위협 · 최후통첩 · 무력 시위 보도 |
| 안내(신규, 제목 아래 1줄) | 없음 | 뉴스에 보도된 군사 위협·최후통첩·무력 시위 건수입니다. 많다고 전쟁이 난다는 뜻은 아닙니다. |
| 막대 소제목 | 최근 90일 일별 언급량 | 최근 90일 하루별 보도량 |
| 목록 소제목 | 최근 14일 주요 사건 | 최근 14일 많이 보도된 사건 |
| 항목 우측 | 언급 N | 보도 N건 |
| 최후통첩 강조 | 최근 14일 안에 최후통첩 신호가 N건 있습니다. | 최근 14일 동안 최후통첩 보도가 N건 있었습니다. |
| 막대 aria-label | 일별 촉매 언급량 | 하루별 위협·경고 사건 보도량 |

## 할 일

1. 사용자에게 제안 문구 확정을 받는다.
2. `CatalystPanel.tsx`, `CatalystItem.tsx`, `CatalystBars.tsx`의 화면 문구를 바꾼다.
3. FAQ·GuideModal에 "촉매" 표현이 있으면 같은 용어로 맞춘다(2026-11-09 기준 없음).
