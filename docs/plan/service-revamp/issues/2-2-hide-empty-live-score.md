# 실시간 점수 없는 대상의 실시간 칸 숨김

## 배경

요약 영역의 "실시간 24시간" 칸은 GDELT 2.0 15분 집계로 기준선을 만들 수 없는 나라·쌍에서 값 대신 "–"와 "기준선 준비 중"을 보여준다(`HomePage.tsx` 110~114행). 일반인에게는 고장처럼 보이고 다음 행동에 도움이 안 된다. 값이 없으면 칸을 통째로 숨긴다.

## 범위

- 포함: 요약 영역의 실시간 24시간 칸(라벨, 숫자, 안내 문구)
- 제외: RiskHistory 차트의 24시간 선, `LiveBadge`, 종합 점수 칸

## 할 일

1. `HomePage.tsx`에서 `summary.live`가 `null`·`undefined`이면 "실시간 24시간" 블록 전체를 렌더링하지 않는다.
2. "기준선 준비 중" 문구를 삭제한다.
3. 실시간 값이 없는 나라 1곳 이상을 찾아 PR에 적는다(`GET /api/countries`에서 `live`가 `null`인 항목).

## 인수 조건

- [ ] `GET /api/countries` 응답에서 `live: null`인 나라를 선택하면 "실시간 24시간" 라벨과 숫자가 DOM에 없다.
- [ ] `live`가 있는 나라(예: 대한민국, `live`가 null이 아닌 경우)를 선택하면 기존처럼 "실시간 24시간"과 점수(소수 1자리)가 보인다.
- [ ] `frontend/src`에서 `기준선 준비 중` grep 결과 0건이다.
- [ ] 실시간 칸이 빠져도 종합 점수 칸과 "종합 점수 구성" 문장이 줄바꿈 깨짐 없이 표시된다(폭 375px·1280px 확인).
- [ ] `frontend`에서 `npx tsc --noEmit`, `npm run lint` 오류 0건이다.
- [ ] 브라우저(`http://localhost:3000`)에서 확인했고 콘솔 오류 0건이다.
