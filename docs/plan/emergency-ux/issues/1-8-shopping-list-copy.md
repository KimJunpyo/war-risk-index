## 배경

- **바꾸는 것:** 계산 결과 아래에 1-3 모델의 장보기 목록을 보인다. 용량 대신 실제로 살 수 있는 단위다.
  - 7·14일 비축: 2L 생수 6병 묶음 수, 휴대용 가스레인지·부탄가스, 쌀·봉지라면·즉석밥·컵라면·레토르트 식품·통조림 개수
  - 3일 가방: "가방에 넣을 몫"(1인 마실 물 2L, 조리 없이 먹는 식량 9끼)과 "집에 둘 몫"(남은 물의 6병 묶음 수)을 나눈다.
- **복사:** "장보기 목록 복사" 버튼으로 메모·메신저에 붙일 글자를 클립보드에 넣는다. 글자는 1-3의 `shoppingText`다.
- **넣지 않는 것:** 브랜드·가격·쇼핑몰 링크(사용자 요청). 품목별 조리 물 수치(근거 없음, plan.md Q5).
