# 계산기 입력: −/+ 버튼·기간 칩·입력 저장

기준 코드: `023aa29`(`main`, 2026-11-18)

## 배경

- **바꾸는 것:** 가구원 수는 숫자 칸에 직접 치는 대신 −/+ 버튼으로 바꾼다. 기간은 누르기 쉬운 칩(3일 가방·7일 비축·14일 비축)으로 바꾼다.
- **숫자 칸은 남긴다(plan.md Q8 결정):** 20명까지 +를 여러 번 누르지 않게 직접 입력도 된다. 기존 검증 안내("1~20 사이 정수로 입력해 주세요")와 테스트 계약(spinbutton "가구원 수")을 그대로 쓴다.
- **입력 저장(plan.md Q7 결정):** 가구원 수와 기간을 이 브라우저에 저장한다(새 키 `war-risk:kit-calc:v1`). 첫 화면 물 카드(1-9)가 같은 값을 쓴다. 위치·검색어가 아니므로 위치 개인정보 원칙에 걸리지 않는다.
- **결과 문구는 그대로다:** "물 84L(약 84kg) · 식량 84끼", "1인당 물 21L · 21끼", 3일 가방 안내, 계산 기준·출처. 장보기 목록은 1-8에서 더한다.

## 범위

- **포함:**
  - `KitCalculator` 입력부: −/+ 버튼, 숫자 칸, 기간 칩
  - 계산 입력 상태 훅(저장·구독. 1-9가 쓴다)
  - 저장 키 `war-risk:kit-calc:v1`, 값 `{ "people": 정수, "period": "bag" | "stock7" | "stock14" }`
  - `e2e/emergency-kit.spec.ts`의 계산기 부분, `e2e/contrast.spec.ts` 계산기 상태
- **제외:**
  - 장보기 목록·복사(1-8)
  - 결과 문구·계산 기준 변경
  - 첫 화면 물 카드(1-9)

## 화면 (plan.md 7-4, 7-7)

- 가구원 수: [줄이기 −] [숫자 칸] [늘리기 +]. 버튼 접근 이름 "가구원 수 줄이기"·"가구원 수 늘리기", 44×44px 이상, 아이콘(aria-hidden).
- 끝값(1·20)에서 버튼은 `aria-disabled="true"`로 둔다. `disabled`를 쓰면 브라우저가 포커스를 버린다(`NearbyShelters` 쪽 이동 버튼과 같은 이유).
- 기간 칩: radiogroup "기간", radio 글자 = `KIT_PERIODS` label, 높이 40px 이상. 기존 `SegmentedControl`을 쓰거나 같은 radiogroup 구조로 만든다.
- 배치: 360은 입력 아래 결과, 768 이상은 입력 왼쪽·결과 오른쪽(지금과 같음).
- 잘못된 값에서 −/+를 누르면 1~20 안으로 맞춘다: 빈칸·0·음수 → 1, 21 이상 → 20, 소수 → 누른 방향의 정수(1.5에서 + → 2, − → 1).

## 인수 조건

- [ ] 4명·7일 비축에서 "가구원 수 늘리기"를 한 번 누르면 1초 안에 칸 값이 5이고, live 영역에 "물 105L(약 105kg) · 식량 105끼"가 보인다. "줄이기"를 누르면 다시 84L다. [테스트]
- [ ] 1명에서 "줄이기"는 `aria-disabled="true"`이고 눌러도 1이다. 20명에서 "늘리기"도 같다. 끝값 버튼을 눌러도 포커스가 그 버튼에 남는다. [테스트]

- [ ] −/+ 버튼이 4폭에서 44×44px 이상이다. [테스트]
