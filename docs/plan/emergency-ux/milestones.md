## M1. 비상 대비 화면을 행동 중심으로 개편

- **만드는 것:**
  - `/emergency` 첫 화면을 "지금 어떤 경보인가요?" 경보 타일 5개와 "미리 준비하기" 카드(가방 진행률·우리 집 물)로 바꾼다.
  - 경보 상세 `/emergency/[alert]` 5개: 핵심 행동 3가지 큰 번호 카드, 공습·핵의 "가까운 대피소 찾기", "더 보기"(알리는 방법·행동요령 전체·출처)
  - 비상 가방은 아이콘 타일로 담고 진행 막대를 본다.
  - 계산기는 −/+ 버튼과 기간 칩으로 입력하고, 결과를 장보기 단위로 보고 복사한다.
- **재사용:** #71 토큰, #72 경보 콘텐츠, #73 목록·계산 함수, #98 메타데이터 방식(plan.md 4-3)
- **독립 확인:** 이 마일스톤만 끝나도 홈 → `/emergency` → 경보 상세 → 홈 대피소, 가방 담기, 계산·장보기 복사를 모두 해 볼 수 있다. M14 없이 온라인에서 완결된다.

**완료 조건**
- **첫 화면:**
  - 360×800에서 `/emergency`를 열면 스크롤 없이 경보 타일 5개가 보이고, 타일마다 `/emergency/{경보 id}`로 간다.
  - "미리 준비하기"에 가방 진행("3일 가방 n/7 챙김"·"7일 비축 n/8 챙김")과 물 카드가 있고, 아래 영역에서 담거나 계산을 바꾸면 1초 안에 카드가 바뀐다.
- **경보 상세:**
  - 빌드 경로 표에서 `/emergency/[alert]`의 사전 렌더 경로가 5개이고 동적(ƒ)이 아니다. 없는 id는 404다.
  - 상세마다 핵심 행동 3가지가 번호 카드로 보이고, "더 보기"를 펼치면 기존 `actions` 전체와 출처가 있다.
  - 공습·핵 상세의 "가까운 대피소 찾기"를 누르면 홈 대피소 영역이 화면 안에 들어오고, 위치는 묻지 않는다.
- **가방:** 타일을 누르면 담기고 진행 막대가 바뀐다. 새로 고쳐도 남고, 개편 전에 체크한 항목도 담긴 상태로 보인다.
- **계산·장보기:**
  - −/+와 칩으로 4명·7일 비축을 고르면 "2L 생수 6병 묶음 7팩(42병, 약 84kg)"과 "부탄가스 24개"가 보인다.
  - 3일 가방이면 가방 몫과 집 몫이 따로 보인다.
  - "장보기 목록 복사"를 누르면 같은 글자가 클립보드로 간다.
- **보존:** 개편 전 `/emergency`에 있던 행동요령 문장과 출처 링크가 상세의 "더 보기" 안에 모두 있다.
- **정적·품질:**
  - 6개 경로를 열 때 브라우저의 API 요청이 0건이다.
  - 4폭에서 가로 스크롤 0, `e2e/contrast.spec.ts`(AA) 통과, 콘솔 오류 0건
  - `sitemap.xml`과 `llms.txt`에 상세 주소 5개가 있다.
- **문서:** plan.md 10절 목록대로 M14 문서·본문을 고칠 준비가 됐다(수정은 메인 세션).
